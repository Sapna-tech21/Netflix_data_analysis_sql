# Project Overview

This project focuses on analyzing the Netflix dataset using SQL to extract meaningful business insights and answer real-world analytical questions.
The analysis covers content distribution, ratings, genres, countries, directors, actors, release trends, and keyword-based categorization.

The objective of this project is to strengthen SQL skills by solving practical KPI-driven business problems using:

Aggregate Functions

GROUP BY & ORDER BY

CTEs

Window Functions

CASE Statements

String Functions

Filtering & Sorting

Date Functions

# Overall Project Insights

## Key Findings

Movies dominate Netflix content distribution.

The USA and India are major content producers.

Mature audience ratings are highly common.

Netflix significantly expanded content after 2018.

Drama and International genres attract major focus.

Long-running TV Shows indicate successful viewer retention.

Metadata quality issues exist in director information.

Indian content growth highlights Netflix’s localization strategy.
